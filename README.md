# D&K — ДНК вашего бизнеса

Одностраничный сайт агентства: шесть секций, анимированная спираль ДНК, карусель проектов и форма заявки с отправкой в Telegram двум получателям.

Сайт работает на Node.js без внешних зависимостей: `npm install` не нужен, сборки нет.

## Запуск

Нужен Node.js 20.12 или новее.

```bash
cp .env.example .env    # затем заполнить .env, см. ниже
npm start               # http://localhost:3000
npm test                # 28 серверных тестов, сеть не нужна
```

`npm run dev` перезапускает сервер при изменении файлов.

## Переменные `.env`

| Переменная | Обязательна | Назначение |
|---|---|---|
| `SITE_URL` | да, в продакшене | Адрес сайта без слэша на конце. Подставляется в canonical, Open Graph, `sitemap.xml`, `robots.txt` |
| `TELEGRAM_BOT_TOKEN` | да | Токен бота от @BotFather |
| `TELEGRAM_CHAT_IDS` | да | ID получателей через запятую |
| `CSRF_SECRET` | да, в продакшене | Случайная строка от 32 символов: `openssl rand -hex 32` |
| `NODE_ENV` | да, в продакшене | `production` включает HSTS, `upgrade-insecure-requests` и флаг `Secure` у cookie |
| `TRUST_PROXY` | если есть прокси | Сколько прокси стоит перед приложением: `0` — напрямую, `1` — nginx, Render, Railway |
| `PORT`, `HOST` | нет | По умолчанию `3000` и `0.0.0.0` |
| `RATE_LIMIT_MAX`, `RATE_LIMIT_WINDOW_MIN` | нет | Лимит заявок с одного IP, по умолчанию 5 за 10 минут |

Без токена или ID получателей сайт запускается, но форма отвечает ошибкой 503 и не показывает успех. При старте сервер пишет в лог, чего не хватает.

## Подключение Telegram

1. **Смените токен.** Токен, который был передан в чате, считается раскрытым. В @BotFather: `/revoke` → выбрать @zayavkibusinesbot → скопировать новый токен.
2. Запишите новый токен в `.env` на сервере: `TELEGRAM_BOT_TOKEN=...`. Больше нигде его хранить не нужно.
3. Запишите получателей: `TELEGRAM_CHAT_IDS=id1,id2`.
4. Каждый получатель открывает бота и нажимает **Start**. Пока человек этого не сделал, Telegram отвечает `403 Forbidden`, и заявка считается недоставленной.
5. Перезапустите сервер и отправьте тестовую заявку с сайта. Сообщение должно прийти обоим.

Правила обращения с токеном:

- только в `.env` на сервере; `.env` уже в `.gitignore`;
- не в коде, не в README, не в `.env.example`, не в переменных с префиксом `NEXT_PUBLIC_` / `VITE_`;
- при любой утечке — сразу `/revoke`.

Сервер не пишет токен в логи: при сетевой ошибке в лог попадает только её тип, а не адрес запроса.

## Как работает заявка

1. Форма проверяет поля в браузере теми же правилами, что и сервер (`public/js/lead-rules.js`).
2. Сервер проверяет лимит по IP, заголовок `Origin`, CSRF-токен, размер и формат тела, поле-ловушку и сами поля.
3. Каждому получателю уходит отдельный запрос `sendMessage`: таймаут 6 секунд, до трёх попыток при сетевой ошибке, 5xx или 429.
4. Пользователь видит «Заявка отправлена» только после `ok: true` от обоих получателей.
5. Если один получил сообщение, а второй нет, форма показывает ошибку. Повторная отправка тех же данных уходит только второму.
6. Одинаковые данные в течение 15 минут доставляются один раз.

Заявки не сохраняются на диск. Если Telegram недоступен дольше трёх попыток, заявка теряется, а пользователь видит ошибку и может отправить её снова.

## Что нужно сделать перед публикацией

- **Превью проектов.** В `public/img/projects/` лежат заглушки с названием проекта, а не скриншоты. Снимите первый экран каждого сайта в размере 1280×800, сохраните в WebP под теми же именами (`<проект>-1280.webp` и уменьшенную копию `<проект>-640.webp`) — код менять не нужно.
- **Политика конфиденциальности.** В `public/privacy.html` выделены места, куда нужно вписать оператора, контакт, срок хранения и дату. Текст стоит показать юристу.
- **Шрифты.** Manrope и Inter подключены с Google Fonts. Для скорости и приватности лучше положить файлы `woff2` в `public/fonts/`, описать их через `@font-face` в `styles.css`, убрать ссылки на Google из трёх HTML-файлов и домены Google из CSP в `src/app.js`.
- **Домен.** Заполните `SITE_URL`.
- **HTTPS.** Приложение не терминирует TLS. Поставьте перед ним nginx / Caddy или разверните на платформе с HTTPS и задайте `TRUST_PROXY=1`.

## Развёртывание

Подойдёт любой хостинг, где можно держать процесс Node.js: VPS с nginx или Caddy, Render, Railway, Fly.io.

Пример для nginx:

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $remote_addr;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

Vercel в текущем виде не подойдёт: лимит запросов и защита от дублей хранятся в памяти процесса, а серверные функции Vercel её не разделяют.

## Структура

```
server.js              запуск: читает .env, поднимает HTTP-сервер
src/
  app.js               маршруты, заголовки безопасности, обработка заявки
  config.js            чтение и проверка переменных окружения
  static.js            раздача public: кэш, сжатие, robots.txt, sitemap.xml
  telegram.js          sendMessage с таймаутом и повторами
  csrf.js              подписанный CSRF-токен (double-submit cookie)
  rate-limit.js        лимит запросов по IP
  ledger.js            защита от повторной отправки
  log.js               логи в JSON без токена и персональных данных
public/
  index.html           главная
  privacy.html         политика конфиденциальности (шаблон)
  404.html
  css/styles.css       дизайн-система на CSS-переменных и все стили
  js/dna.js            анимация спирали
  js/carousel.js       карусель проектов
  js/lead-form.js      форма: маска телефона, состояния, отправка
  js/lead-rules.js     правила проверки заявки — общие для браузера и сервера
  js/nav.js            меню и подсветка текущей секции

  favicon.svg

```

## Что где менять

- Цвета, шрифты, размеры, отступы, радиусы — переменные в начале `public/css/styles.css`.
- Цвет кнопок — `--btn-bg` и `--btn-fg` там же.
- Скорость спирали — атрибут `data-period` (секунды на полный оборот) у блока `data-helix` в `index.html`.
- Тексты, услуги, цены, проекты — `public/index.html`. Цены продублированы в блоке JSON-LD в `<head>`.

## Безопасность

- Content-Security-Policy без `unsafe-inline`: скрипты и стили только со своего домена, шрифты — с Google Fonts.
- `X-Frame-Options: DENY`, `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`, HSTS в продакшене.
- CORS-заголовки не выставляются: API доступно только со своего домена.
- Пользовательский ввод не вставляется в HTML; в Telegram уходит обычный текст без разметки.
- Сообщения об ошибках для пользователя не содержат внутренних деталей.

Клиентский код виден любому посетителю — защита строится на серверной части. Лимиты и защита от дублей хранятся в памяти одного процесса и сбрасываются при перезапуске.
